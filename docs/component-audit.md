## Устройство

Cordis объединяет плагины в приложение: адаптер модели, реестр инструментов, журнал сеансов и агентный цикл заменяются конфигурацией. Профиль задаёт набор пакетов; слои конфигурации позволяют изменить его состав. Журнал хранит события диалога и исполнения инструментов.

Источник: [архитектура](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/architecture.md).

Desktop — Electron-оболочка общего веб-приложения с локальным Host. В поставке предусмотрены Python, Node.js, pnpm и библиотеки Office, в том числе python-docx. Это полезная основа; соответствие инструментов требованиям нашей карты пока не установлено.

Источник: [Desktop README](https://github.com/deepseek-ai/deepseek-harness/blob/master/apps/desktop/README.md).

Веб-приложение предоставляет чат, историю и настройки; его набор инструментов определяется пресетами агента. Базовый пакет включает файловые инструменты, команды, веб-инструменты, подагентов и отслеживание задач, а также политику разрешений и телеметрию.

Источники: [Web bundle](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/bundle/web-app/README.md), [Base bundle](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/bundle/base/README.md).

## Ограничения и ближайшие действия

Проект находится в developer preview; README предупреждает о несовместимых изменениях. Для воспроизводимого запуска необходимо закрепить ревизию. Лицензия проекта — MIT; сторонние лицензии учитываются отдельно.

Источник: [официальный репозиторий](https://github.com/deepseek-ai/deepseek-harness).

На Windows официально допускается нативная разработка; WSL 2 необязателен. Заявлены Node.js 22.19+ или 24+ и закреплённый pnpm 11.7.0; требования нужно сверить с выбранной ревизией перед установкой.

Источник: [руководство разработки](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/development.md).

Следующие действия: согласовать функции, получить исходники на закреплённом коммите, изучить инструкции репозитория, собрать и запустить исходный вариант, измерить нагрузку. Затем менять профиль и приложение с повторными измерениями. Выбор локальной модели отложен по указанию пользователя.

## Что означает отключение менеджера плагинов

Менеджер позволяет включать и выключать записи плагинов, выбирать пакеты расширений, устанавливать и удалять внешние пакеты. Изменения относятся ко всему профилю. Его веб-страница и инструмент `plugin_manager` используют общий сервис; инструмент по умолчанию включён в Creator, а в остальных пресетах выключен. CLI также предоставляет команды управления.

Источник: [Plugin Manager](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/boot/plugin-manager/README.md).

Возможные уровни изменения нашего приложения:

- Убрать только страницу из интерфейса: пользователь теряет кнопки управления; внутренний сервис и другие пути управления могут остаться.
- Также отключить инструмент для модели: агент не сможет управлять составом через `plugin_manager`; уже подключённые функции продолжают работать.
- Удалить сервис управления и пути установки из поставки: приложение получает фиксированный состав расширений. Зависимости необходимо проверить перед удалением; CLI и другие пути управления рассматриваются отдельно.

Внутренний загрузчик плагинов Cordis требуется сохранить для работы выбранных компонентов. Удаление менеджера не означает отказа от архитектуры плагинов. Новый проверенный функционал можно добавлять обновлением приложения. Для будущего интернет-модуля наличие пользовательского магазина расширений не обязательно.

Решение пользователя от 3 октября 2026 года: плагины и менеджер плагинов сохранить. Прежнее предложение убрать страницу управления не принято. Остальной предложенный состав приложения принят; точный перечень записан в decisions.md. Самостоятельная установка расширений агентом отдельно не разрешена. Экономия ресурсов не измерена.
