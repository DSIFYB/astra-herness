## Установка и подключение подагентов

Дата: 4 октября 2026 года. Последующие прямые запросы пользователя разрешили установку необходимых компонентов, сохранение продукта в GitHub и подключение подагентов разработки. Это заменяет ограничение предыдущего этапа «только обсуждение», но не превращает вложенную карту в самостоятельное поручение.

- Подключены два подагента Codex: GPT-6 Luna Medium для простого кода и GPT-6 Luna Low (Light) для проверок и тестов. Модель основного чата этим не переключена.
- Установлены и собраны закреплённый DeepSeek Harness, llama.cpp CUDA и Qwen3.5-2B Q4_K_M. Подготовлено изолированное Python-окружение для документных библиотек.
- Рабочий контекст первого теста увеличен с предположенных 4096 до 8192 из-за резерва 4096 токенов в установленном SDK Harness. Температура первого документного теста закреплена на 0.
- Доступ интеграции GitHub восстановлен: обновление README через Contents API прошло успешно. Исходники продукта, профиль, тесты и документы сохраняются в DSIFYB/astra-herness; веса, сеансы, личные документы и секреты исключены.
- Подагенты разработки не включают инструменты подагентов внутри локального продукта: ранее согласованный состав первой версии сохранён.
